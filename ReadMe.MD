# Curriculhub - API

The RESTful API powering the Curriculhub ecosystem. Built with a focus on scalability, security, and predictable error handling.

## Tech Stack & Key Tools

- ToolsRuntime & Framework: Node.js, Express
- Database: MongoDB / Mongoose
- Security & Auth: Argon2id
- password hashing, JWT
- Validation: Zod
- Logging: Pino
